# 竞品时间段监控工作流使用说明

## 📋 工作流概述

该工作流分为三个独立部分：
1. **数据提取** - 从数据库提取指定时间范围内的社媒数据
2. **AI分析** - 对提取的数据进行AI分析（重点关注玩法更新和线下活动）
3. **报告生成** - 生成飞书日报并发送（按公司分开，包含监控时间段和平台信息）

## 🚀 快速开始

### 完整工作流（推荐）

运行完整流程，包括数据提取、AI分析和报告生成：

```powershell
# 提取最近7天的数据并生成报告
python CompetitorPeriodWorkflow.py --start-date 2026-01-07 --end-date 2026-01-13

# 不发送到飞书，只生成报告文件
python CompetitorPeriodWorkflow.py --start-date 2026-01-07 --end-date 2026-01-13 --skip-send
```

### 分步执行

#### 方式1：只执行第一部分（数据提取）

```powershell
python CompetitorPeriodWorkflow.py --start-date 2026-01-07 --end-date 2026-01-13 `
    --skip-analysis --skip-report
```

输出文件：`output/competitor_extracted_data_2026-01-07_to_2026-01-13.json`

#### 方式2：只执行第二部分（AI分析）

```powershell
python CompetitorPeriodWorkflow.py --start-date 2026-01-07 --end-date 2026-01-13 `
    --skip-extract --skip-report `
    --extracted-data output/competitor_extracted_data_2026-01-07_to_2026-01-13.json
```

输出文件：`output/competitor_analysis_result_2026-01-07_to_2026-01-13.json`

#### 方式3：只执行第三部分（报告生成）

```powershell
python CompetitorPeriodWorkflow.py --start-date 2026-01-07 --end-date 2026-01-13 `
    --skip-extract --skip-analysis `
    --analysis-result output/competitor_analysis_result_2026-01-07_to_2026-01-13.json
```

或者直接调用报告生成模块：

```powershell
python CompetitorPeriodReportGenerator.py `
    --input output/competitor_analysis_result_2026-01-07_to_2026-01-13.json
```

### 高级选项

#### 指定公司

```powershell
python CompetitorPeriodWorkflow.py --start-date 2026-01-07 --end-date 2026-01-13 `
    --companies voodoo "vita studio"
```

#### 指定数据库路径

```powershell
python CompetitorPeriodWorkflow.py --start-date 2026-01-07 --end-date 2026-01-13 `
    --db-path path/to/competitor_data.db
```

#### 指定输出目录

```powershell
python CompetitorPeriodWorkflow.py --start-date 2026-01-07 --end-date 2026-01-13 `
    --output-dir path/to/output
```

## 📊 输出文件说明

### 中间产物

1. **提取数据** (`competitor_extracted_data_YYYY-MM-DD_to_YYYY-MM-DD.json`)
   - 包含时间段内所有公司的原始社媒数据
   - 格式：按公司和平台组织的数据结构

2. **分析结果** (`competitor_analysis_result_YYYY-MM-DD_to_YYYY-MM-DD.json`)
   - 包含AI分析结果
   - 重点关注玩法更新和线下活动
   - 每个平台有评分（玩法更新和线下活动8-10分，日常维护1-3分）

3. **报告文件** (`competitor_period_reports_YYYY-MM-DD_to_YYYY-MM-DD.json`)
   - 包含生成的飞书卡片JSON
   - 可以直接用于发送到飞书

## 🔧 环境要求

1. **数据库**：确保 `db/competitor_data.db` 存在且包含数据
2. **API密钥**：需要配置 `OPENROUTER_API_KEY` 或 `OPENAI_API_KEY` 环境变量（用于AI分析）
3. **飞书配置**：需要配置 `FEISHU_WEBHOOK_URL` 环境变量或 `config/config.yaml` 中的 `notification.webhooks.feishu_url`（用于发送报告）

## 💡 使用技巧

1. **先测试再发送**：首次运行建议使用 `--skip-send` 参数，先查看生成的文件，确认无误后再去掉该参数发送到飞书

2. **分步执行**：
   - 如果数据提取时间较长，可以先提取数据
   - AI分析需要调用API，如果失败可以重新执行第二部分
   - 报告生成可以多次执行（不重新分析），只需要重新执行第三部分

3. **查看中间产物**：
   - 所有中间产物都保存在 `output/` 目录下
   - 可以随时查看JSON文件了解数据结构和分析结果

4. **Windows PowerShell 注意事项**：
   - 如果遇到编码问题，可以设置环境变量：`$env:PYTHONIOENCODING="utf-8"`
   - 使用反引号 ` 进行换行

## ⚠️ 常见问题

### Q1: 监控平台数显示为0
**已修复**：代码已更新，现在会正确查询包括游戏级平台在内的所有平台。

### Q2: 没有发送到飞书
- 检查是否使用了 `--skip-send` 参数
- 检查飞书webhook配置是否正确
- 查看终端输出是否有错误信息

### Q3: AI分析失败
- 检查API密钥是否正确配置
- 检查网络连接
- 查看终端输出的错误信息

### Q4: 数据库查询不到数据
- 确认数据库路径正确
- 确认数据库中存在对应时间段的数据
- 检查公司名称是否与数据库中的名称完全匹配（大小写敏感）

## 📝 示例命令

```powershell
$endDate = (Get-Date).ToString("yyyy-MM-dd")
$startDate = (Get-Date).AddDays(-7).ToString("yyyy-MM-dd")
python CompetitorPeriodWorkflow.py --start-date $startDate --end-date $endDate
```

### 只分析特定公司

```powershell
    --companies voodoo --skip-send
```

### 重新生成报告（不重新分析）
```powershell
python CompetitorPeriodWorkflow.py --start-date 2026-01-07 --end-date 2026-01-13 `
    --skip-extract --skip-analysis `
    --analysis-result output/competitor_analysis_result_2026-01-07_to_2026-01-13.json
```

## 🎯 工作流特性

1. ✅ **三部分独立执行**：每个部分都可以单独运行
2. ✅ **中间产物保存**：所有步骤自动保存JSON文件
3. ✅ **AI分析重点**：重点关注玩法更新和线下活动，评分高的优先展示
4. ✅ **完整信息**：报告包含监控时间段、监控平台、AI分析结果
5. ✅ **按公司分开**：每个公司生成独立的飞书卡片
