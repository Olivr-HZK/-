# 数据库查看工具推荐

## 📋 概述

本文档推荐几种查看 SQLite 数据库（`db/competitor_data.db`）的工具和方法。

## 🔌 VS Code / Cursor 插件（推荐）

### 1. SQLite Viewer

**插件名称：** `SQLite Viewer`  
**作者：** `qwtel`  
**插件 ID：** `qwtel.sqlite-viewer`

**安装方法：**
1. 打开 VS Code/Cursor
2. 按 `Cmd+Shift+X` (Mac) 或 `Ctrl+Shift+X` (Windows) 打开扩展市场
3. 搜索 "SQLite Viewer"
4. 点击安装

**使用方法：**
- 在文件资源管理器中右键点击 `db/competitor_data.db`
- 选择 "Open Database" 或 "Open with SQLite Viewer"
- 可以查看表结构、数据和执行 SQL 查询

### 2. SQLite

**插件名称：** `SQLite`  
**作者：** `alexcvzz`  
**插件 ID：** `alexcvzz.vscode-sqlite`

**特点：**
- 支持 SQL 查询
- 可以编辑数据
- 支持导出数据

### 3. Database Client

**插件名称：** `Database Client`  
**作者：** `Weijan Chen`  
**插件 ID：** `cweijan.vscode-database-client2`

**特点：**
- 支持多种数据库（SQLite, MySQL, PostgreSQL 等）
- 图形化界面
- 支持 SQL 查询和编辑

## 💻 命令行工具

### 1. sqlite3（macOS/Linux 自带）

```bash
# 打开数据库
sqlite3 db/competitor_data.db

# 查看所有表
.tables

# 查看表结构
.schema table_name

# 查询数据
SELECT * FROM table_name LIMIT 10;

# 退出
.quit
```

### 2. 安装 sqlite3（如果没有）

**macOS:**
```bash
# 通常已自带，如果没有：
brew install sqlite3
```

**Linux:**
```bash
sudo apt-get install sqlite3
```

**Windows:**
- 下载 SQLite 命令行工具：https://www.sqlite.org/download.html

## 🐍 Python 脚本查看

你也可以使用 Python 快速查看数据库：

```python
import sqlite3
from database.competitor_db import CompetitorDatabaseDB

# 方法一：使用项目中的类
db = CompetitorDatabaseDB()
companies = db.list_all_companies()
print("数据库中的公司:", companies)

# 方法二：直接使用 sqlite3
conn = sqlite3.connect('db/competitor_data.db')
cursor = conn.cursor()

# 查看所有表
cursor.execute("SELECT name FROM sqlite_master WHERE type='table';")
tables = cursor.fetchall()
print("所有表:", tables)

# 查看某个表的数据
cursor.execute("SELECT * FROM companies LIMIT 10;")
rows = cursor.fetchall()
for row in rows:
    print(row)

conn.close()
```

## 📊 项目中的数据库结构

### 主要表

1. **`companies`** - 公司基本信息
2. **`company_platforms`** - 公司平台配置
3. **`{company}_raw_data`** - 每个公司的原始数据表（动态创建）

### 查看数据库结构

```bash
# 使用 sqlite3 命令行
sqlite3 db/competitor_data.db

# 查看所有表
.tables

# 查看表结构
.schema companies
.schema company_platforms
```
