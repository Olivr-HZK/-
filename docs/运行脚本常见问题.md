# 运行脚本常见问题

## ❌ ModuleNotFoundError: No module named 'env_loader'

### 问题原因

直接运行 Python 脚本时，Python 的模块搜索路径不包含项目根目录，因此找不到 `env_loader` 等模块。

### 解决方案

#### 方法一：激活虚拟环境并设置 PYTHONPATH（推荐）

```bash
# 在项目根目录运行
cd /Users/oliver/guru/-

# 激活虚拟环境
source .venv/bin/activate

# 设置 PYTHONPATH
export PYTHONPATH="$(pwd):$PYTHONPATH"

# 运行脚本
python3 scrapers/daily_scraper.py --days-ago 1
```

或者一行命令：

```bash
cd /Users/oliver/guru/- && source .venv/bin/activate && export PYTHONPATH="$(pwd):$PYTHONPATH" && python3 scrapers/daily_scraper.py --days-ago 1
```

#### 方法二：使用提供的脚本（最简单）

使用项目提供的脚本，它们已经设置了正确的路径：

```bash
# macOS/Linux
./run-daily-scraper.sh

# Windows PowerShell
.\run-daily-scraper.ps1
```

#### 方法三：从项目根目录使用 python -m

```bash
# 在项目根目录
cd /Users/oliver/guru/-
python3 -m scrapers.daily_scraper --days-ago 1
```

#### 方法四：在脚本中添加路径（临时方案）

在脚本开头添加：

```python
import sys
import os
# 添加项目根目录到 Python 路径
project_root = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
if project_root not in sys.path:
    sys.path.insert(0, project_root)
```

### 永久设置 PYTHONPATH（可选）

如果经常需要直接运行脚本，可以在 shell 配置文件中设置：

**macOS/Linux (.zshrc 或 .bashrc):**
```bash
export PYTHONPATH="/Users/oliver/guru/-:$PYTHONPATH"
```

**Windows PowerShell (profile):**
```powershell
$env:PYTHONPATH = "C:\path\to\project;$env:PYTHONPATH"
```
