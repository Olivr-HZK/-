# 定时任务脚本使用说明

## 📋 概述

项目提供了两个 PowerShell 脚本用于自动化定时任务：

1. **`run-daily-scraper.ps1`** - 每日爬取任务（爬取前一天的社媒数据）
2. **`run-weekly-period-workflow.ps1`** - 每周周报生成任务（生成上周的竞品周报）

## 🚀 快速开始

### 1. 每日爬取任务

#### 功能说明
- 每天自动运行一次
- 爬取**前一天**的所有竞品社媒更新信息
- 自动保存日志到 `logs/` 目录

#### 手动测试

```powershell
# 在项目根目录执行
.\run-daily-scraper.ps1
```

#### 配置 Windows 任务计划程序

1. **打开任务计划程序**
   - 按 `Win + R`，输入 `taskschd.msc` 并回车

2. **创建基本任务**
   - 任务名称：`竞品数据每日爬取`
   - 描述：`每天自动爬取前一天的竞品社媒数据`

3. **设置触发器**
   - 触发器：每天
   - 开始时间：建议设置为 **每天 08:00**（可根据需要调整）
   - 重复间隔：1 天

4. **设置操作**
   - 操作：启动程序
   - 程序或脚本：`powershell.exe`
   - 添加参数：`-ExecutionPolicy Bypass -File "C:\path\to\project\run-daily-scraper.ps1"`
   - 起始于：项目根目录的完整路径，例如：`C:\Users\oliver\guru\-`

5. **完成配置**
   - 勾选"当单击完成时，打开此任务属性的对话框"
   - 在"常规"选项卡中，勾选"不管用户是否登录都要运行"
   - 在"条件"选项卡中，取消勾选"只有在计算机使用交流电源时才启动此任务"（如果使用笔记本）

### 2. 每周周报生成任务

#### 功能说明
- 每周自动运行一次
- 生成**上周**（周一到周日）的竞品周报
- 自动计算上周的日期范围
- 自动保存日志到 `logs/` 目录

#### 手动测试

```powershell
# 在项目根目录执行
.\run-weekly-period-workflow.ps1
```

#### 配置 Windows 任务计划程序

1. **打开任务计划程序**
   - 按 `Win + R`，输入 `taskschd.msc` 并回车

2. **创建基本任务**
   - 任务名称：`竞品周报每周生成`
   - 描述：`每周自动生成上周的竞品社媒周报`

3. **设置触发器**
   - 触发器：每周
   - 开始时间：建议设置为 **每周一 09:00**（可根据需要调整）
   - 重复间隔：1 周
   - 选择星期：周一

4. **设置操作**
   - 操作：启动程序
   - 程序或脚本：`powershell.exe`
   - 添加参数：`-ExecutionPolicy Bypass -File "C:\path\to\project\run-weekly-period-workflow.ps1"`
   - 起始于：项目根目录的完整路径

5. **完成配置**
   - 勾选"当单击完成时，打开此任务属性的对话框"
   - 在"常规"选项卡中，勾选"不管用户是否登录都要运行"
   - 在"条件"选项卡中，取消勾选"只有在计算机使用交流电源时才启动此任务"（如果使用笔记本）

## 📝 日志文件

所有脚本执行日志都会自动保存到 `logs/` 目录：

- **每日爬取日志**：`logs/daily_scraper_YYYY-MM-DD.log`
- **每周周报日志**：`logs/weekly_period_workflow_YYYY-MM-DD.log`

日志文件包含：
- 执行开始和结束时间
- 执行结果（成功/失败）
- 执行时长
- 详细的输出信息

## ⚙️ 脚本配置选项

### 每日爬取脚本 (`run-daily-scraper.ps1`)

如果需要修改爬取参数，可以编辑脚本中的这一行：

```powershell
# 默认爬取前一天的数据（days-ago=1）
& python scrapers/daily_scraper.py --days-ago 1 2>&1 | Tee-Object -FilePath $logFile -Append

# 如果需要爬取指定公司的数据，可以添加 --companies 参数
# & python scrapers/daily_scraper.py --days-ago 1 --companies "dream games" "vita studio" 2>&1 | Tee-Object -FilePath $logFile -Append
```

### 每周周报脚本 (`run-weekly-period-workflow.ps1`)

如果需要修改发送选项，可以编辑脚本中的这一行：

```powershell
# 默认会发送到飞书
& python workflows/period_workflow.py --start-date $startDate --end-date $endDate 2>&1 | Tee-Object -FilePath $logFile -Append

# 如果只想生成报告文件而不发送，取消下面这行的注释
# & python workflows/period_workflow.py --start-date $startDate --end-date $endDate --skip-send 2>&1 | Tee-Object -FilePath $logFile -Append
```

## 🔧 虚拟环境配置

如果项目使用虚拟环境，需要在脚本中取消注释虚拟环境激活行：

```powershell
# 在脚本开头找到这一行，取消注释并修改路径
& .\.venv\Scripts\Activate.ps1
```

## ❓ 常见问题

### 1. PowerShell 执行策略错误

如果遇到"无法加载文件，因为在此系统上禁止运行脚本"的错误：

```powershell
# 以管理员身份运行 PowerShell，执行：
Set-ExecutionPolicy RemoteSigned
```

### 2. Python 命令未找到

确保 Python 已添加到系统 PATH 环境变量中，或者使用完整路径：

```powershell
# 修改脚本中的 python 命令为完整路径
& C:\Python\python.exe scrapers/daily_scraper.py --days-ago 1
```

### 3. 任务计划程序无法运行

- 确保在任务属性中勾选了"不管用户是否登录都要运行"
- 确保"运行身份"设置为有足够权限的账户
- 检查日志文件查看具体错误信息

### 4. 日志目录不存在

脚本会自动创建 `logs/` 目录，如果创建失败，请检查项目目录的写入权限。
