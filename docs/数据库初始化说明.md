# 数据库初始化说明

## 📋 概述

在使用爬虫脚本之前，需要先将公司配置导入到数据库中。本文档说明如何初始化数据库。

## 🚀 快速开始

### 方法一：从 JSON 文件加载（推荐）

如果你有 `input/twitter_input.json` 配置文件：

```bash
# 加载所有公司配置到数据库
python tools/load_companies.py

# 或者指定 JSON 文件路径
python tools/load_companies.py --json-path path/to/your/config.json
```

### 方法二：使用导入工具

```bash
# 导入 King 公司（示例）
python tools/import_company.py

# 重新加载公司配置
python tools/reload_companies.py
```

## 📝 JSON 配置文件格式

`input/twitter_input.json` 文件应包含以下格式：

```json
{
  "competitors": [
    {
      "name": "公司名称",
      "priority": "high",
      "platforms": [
        {
          "type": "twitter",
          "enabled": true,
          "username": "company_twitter",
          "url": "https://twitter.com/company_twitter",
          "user_id": ""
        },
        {
          "type": "instagram",
          "enabled": true,
          "username": "company_instagram",
          "url": "https://www.instagram.com/company_instagram/"
        },
        {
          "type": "tiktok",
          "enabled": true,
          "username": "company_tiktok",
          "url": "https://www.tiktok.com/@company_tiktok"
        },
        {
          "type": "youtube",
          "enabled": true,
          "handle": "@company_youtube",
          "url": "https://www.youtube.com/@company_youtube"
        },
        {
          "type": "facebook",
          "enabled": true,
          "url": "https://www.facebook.com/company_facebook",
          "page_id": ""
        }
      ],
      "games": [
        {
          "name": "游戏名称",
          "platforms": [
            {
              "type": "twitter",
              "enabled": true,
              "username": "game_twitter",
              "url": "https://twitter.com/game_twitter"
            }
          ]
        }
      ]
    }
  ]
}
```

## 🔍 检查数据库状态

### 查看数据库中的公司

你可以使用 Python 脚本检查数据库：

```python
from database.competitor_db import CompetitorDatabaseDB

db = CompetitorDatabaseDB()
companies = db.list_all_companies()
print(f"数据库中的公司: {companies}")
```

### 查看数据库文件

数据库文件位置：`db/competitor_data.db`

## ❓ 常见问题

### Q1: 提示 "数据库中未找到任何公司"

**原因：** 数据库是空的，还没有导入公司配置。

**解决方案：**
1. 准备 `input/twitter_input.json` 配置文件
2. 运行 `python tools/load_companies.py` 导入配置
3. 或者使用 `python tools/import_company.py` 导入单个公司

### Q2: 提示 "JSON 配置文件不存在"

**原因：** 缺少 `input/twitter_input.json` 文件。

**解决方案：**
1. 创建 `input/` 目录：`mkdir -p input`
2. 创建 `input/twitter_input.json` 文件，按照上面的格式填写公司配置
3. 运行 `python tools/load_companies.py` 导入配置

### Q3: 如何更新公司配置？

**方法一：** 修改 JSON 文件后重新加载
```bash
python tools/reload_companies.py
```

**方法二：** 直接使用 load_companies.py
```bash
python tools/load_companies.py --json-path input/twitter_input.json
```

### Q4: 数据库文件在哪里？

默认位置：`db/competitor_data.db`

可以通过环境变量 `COMPETITOR_DB_DIR` 指定其他目录。

## 📚 相关工具

- **`tools/load_companies.py`** - 从 JSON 加载所有公司配置
- **`tools/reload_companies.py`** - 重新加载公司配置
- **`tools/import_company.py`** - 导入单个公司（King 示例）
